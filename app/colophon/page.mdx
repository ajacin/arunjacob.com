# Colophon

This site is a Next.js App Router project written in TypeScript. Pages are MDX files rendered through @next/mdx, and styling is Tailwind CSS 4 set in Geist Sans.

Code blocks are highlighted with sugar-high, diagrams are rendered with Mermaid, and page views are measured with Vercel Analytics. The site is deployed on Vercel.

The layout is inspired by [leerob.com](https://leerob.com) and started from [leerob/next-mdx-blog](https://github.com/leerob/next-mdx-blog); the content, structure, and components are my own.
